# Proyecto KD-Tree y Regresión Lineal

Este proyecto simula datos meteorológicos (temperatura, humedad y presión)
y aplica un KD-Tree para realizar búsquedas eficientes por rango.
Además, se utiliza un modelo de regresión lineal para predecir la temperatura.

## Tecnologías utilizadas
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Funcionalidades
- Generación de datos aleatorios
- Construcción de KD-Tree
- Búsqueda por rango (KD-Tree vs búsqueda secuencial)
- Comparación de tiempos de ejecución
- Regresión lineal y visualización de resultados
